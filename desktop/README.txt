KEEPS FOR WINDOWS - PORTABLE PROTOTYPE

1. Download and extract the Keeps-Windows-x64 artifact ZIP.
2. Double-click Keeps-1.0.0-Windows-x64.exe. No Keeps installation is needed.
3. Use Load walkthrough data to prepare the sample outing.
4. Click a chat message to save it directly into a plan.

Works offline, except for opening external booking or ticket links.
Desktop data is saved separately from the website in your Windows profile.
Your browser data is not automatically copied into the desktop app.
The app is a local demo: no live chat, payments, or real invitations.

This is an unsigned student prototype, not a code-signed commercial release.
The artifact also includes SHA256SUMS.txt for checking the download.

ALT shows the menu. F11 toggles full screen. Ctrl+R reloads the app.
